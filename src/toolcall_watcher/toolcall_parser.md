# `toolcall_parser`

Parses `toolcall.<N>` trace files generated by `agentlib::tool_tracer` (`--tooltrace`) for live demo display in `turbostar-toolcall-watcher`.

## Goals & Constraints
- **Numeric Ordering**: `scan_directory` parses the numeric suffix of `toolcall.<uint>` so `toolcall.10` sorts after `toolcall.9`.
- **Mid-Write Resilience**: `tool_tracer` writes directly with `std::ios::trunc`. If a polled file lacks `\n---\n` or has incomplete JSON, `parse_content` returns `std::nullopt` so the caller can keep displaying the previous valid trace until the next poll tick.
- **Untrusted Input Sanitization**: Strips ESC (`0x1b`) and ASCII control bytes before passing trace text to ncurses, and strips matching outer `<*_result>...</*_result>` wrapper tags for cleaner demo output.

## Lessons Learned
- Initial implementation: keep C-style header formatting compact by collapsing whitespace and truncating individual argument values at 36 characters so the title bar remains single-line.
