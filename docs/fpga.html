Hardware, RTL & FPGA Engineering

The Missing Glue Between AI Agents & Hardware Design

Software agents thrive on text diffs and stack traces, but digital hardware lives in clock edges, combinational LUT cones, and gigabyte waveform dumps. Turbostar's verilog tool family bridges the divide—giving LLM agents natural, deterministic primitives for SystemVerilog linting, tiered simulation, cycle-accurate VCD inspection, LUT area & logic depth analysis, and physical place-and-route timing closure.

Why Hardware Agents Need Purpose-Built Glue

With raw shell commands, RTL design is hostile to AI agents. With the right primitives, the workflow becomes effortless.

Ask an unassisted coding agent to build or debug a CPU core in SystemVerilog using only bash and grep: a single simulation emits a 500 MB .vcd dump that overflows the context window, running Verilator on a multi-testbench directory fails with duplicate top modules, and "optimizing" a critical path blindly unrolls multiplexers until LUT area explodes and physical routing fails timing.

Turbostar acts as the domain-aware translation layer between open-source EDA toolchains (Verilator, Yosys, and nextpnr) and the agent. Every tool accepts high-level intent—module names, clock-cycle windows, enum state symbols, and target frequencies—and returns compact, line-attributed engineering reports with inline RTL statements. Tested end-to-end by autonomous agents designing a 12-module, 34-testbench Intel 8080 CPU core from scratch—and subsequently used to push a design's physical place-and-route clock frequency from 50 MHz to 75 MHz Fmax (+50%) in just a couple of hours—the tools feel completely natural to the model at every step of the RTL lifecycle.

Dual-Engine Lint & Synthesis Triage

Catch hardware bugs before a single clock cycle is simulated. verilog_compile combines ultra-fast Verilator static linting (lint_only=true in ~0.13s) with full Yosys RTL synthesis checks in a single unified tool.

  • Automatic Hierarchy Isolation: Pass module="cpu" and Turbostar automatically scopes the module's hierarchy across the RTL tree, resolves dependencies, and excludes unrelated testbenches—preventing duplicate symbol errors.
  • Structured Diagnostic Reporting: Compiler logs are cleanly separated into synthesis hazards vs. style and unused resource notes (UNUSEDPARAM, UNUSEDSIGNAL, PINMISSING) with exact file.sv:line locations.
  • Fast Inner Loop to Full PnR: Use lint_only=true for lightning-fast sub-second syntax checks during coding, then run full synthesis + nextpnr place-and-route with cell statistics before committing.

Tiered Simulation & Auto-Diffing Waveforms

Hardware verification requires fast inner loops during active debugging and exhaustive sweeps before sign-off. verilog_simulate and verilog_configure_testbench manage testbench execution and waveform history automatically.

  • Quick, Comprehensive & Extreme Levels: Classify testbenches by level (level="quick") so the agent runs sub-second unit tests after every edit and full instruction-set regressions before committing.
  • Hierarchical Bottom-Up Verification: Pass hierarchical=true on top modules to automatically compile all testbenches in parallel across CPU cores and run them in topological dependency order (e.g. decode_mod → alu8 → cpu → top).
  • Automatic Waveform Snapshots & Diffs: Passing runs snapshot .lastpass.vcd while every run preserves .previous.vcd. When a change breaks a testbench, verilog_simulate automatically diffs the new trace against the baseline and reports the exact diverging clock cycle and signal.

Cycle-Accurate VCD Waveform Intelligence

Instead of dumping megabyte VCD text into the model's prompt, Turbostar's 7-tool VCD suite gives the agent an interactive logic analyzer tailored specifically for LLM context windows.

  • Live SystemVerilog Enum Discovery: Automatically parses RTL typedef enum declarations—rendering state machines as 0x1 (FETCH), 0x6 (STORE16_1), or 0x8 (RETIRE) instead of cryptic raw numbers.
  • Zero-Toggle Inactive Net Detection: vcd_file_info flags signals with zero transitions with **, immediately surfacing stuck resets, unwired nets, or dead control logic without manual inspection.
  • Strobe Qualification & Opcode Labels: Pair data buses with valid strobes via vcd_signal_qualifier so inactive cycles render as -, and register project-wide instruction decodes via vcd_signal_labels to label hex opcodes as readable mnemonics (e.g. 0xCD → CALL).

Logic Depth, LUT Area & In-Place Port Annotations

Agents optimizing purely for clock frequency often duplicate logic cones until FPGA resource utilization explodes. verilog_logic_depth and verilog_update_timing give the agent simultaneous visibility into combinational depth and resource area in seconds.

  • Bottleneck Sink Grouping & Inline RTL: Critical paths are grouped by destination sink with project-relative file.sv:line coordinates and inline 1-line SystemVerilog statements (show_code=1 default), decomposing each stage into LUT levels and carry chain hops.
  • Module Area Summary: Every report includes a synthesized cell breakdown (LUTs, Flip-Flops, Carry cells, and Total Cells) so the agent balances speed against logic budgets.
  • In-Place // [timing: ...] Port Annotations: verilog_update_timing (and turbostar-verilog -u) writes and updates vertically aligned timing comments directly on module port declarations in .sv files—giving agents instant awareness of deep inputs and outputs as they wire modules together.

- Sources: `alu.flags` (src/alu8.sv:62), `decode.opcode_valid` (src/decode.sv:138)
  1. `src/alu8.sv:178` (5 LUTs) -> `alu_out` | `{carry, alu_out} = in1_reg - imm8_reg;`

Physical Place-and-Route Timing Closure

Pre-synthesis logic depth is only half the story—on real FPGAs, long Manhattan wire routes and high-fanout control nets often dominate the critical path. verilog_pnr_timing runs full Yosys synthesis + nextpnr physical placement and routing on demand, enabling agents to drive a design from 50 MHz to 75 MHz Fmax (+50%) in a couple of hours.

  • Multi-Seed Fmax & Submodule PnR: Evaluates real post-routing setup slack across placement seeds against your target clock constraint, or runs unconstrained out-of-context PnR on individual submodules (module="alu8").
  • Wire-Driver Disambiguation & Inline Code: Resolves shared always_ff blocks and multi-instance submodules to their exact register names via Yosys wire connectivity, displaying the offending RTL statement inline at every hop without extra read_file round-trips.
  • Physical Tile Distance, Fanout & Segments: Reports net fanout and chip tile span alongside logic vs. routing delay splits, with optional hop-by-hop cell/pin inspection (show_segments=true).

Standalone Unified CLI for Human Engineers

Why should AI agents have all the fun? turbostar-verilog packages the entire FPGA timing, configuration, compilation, simulation, and VCD waveform suite into a standalone command-line binary you can run directly in your terminal, Makefiles, or CI pipelines without launching the editor or MCP server.

  • Timing & In-Place Port Annotations (timing / default): Run turbostar-verilog -m alu_mod for instant LUT depth tables, --pnr for multi-seed Yosys + nextpnr physical timing closure, or -u, --update to write aligned // [timing: ...] port annotations directly in .sv files.
  • Project Setup, Compile & Simulate (config, compile, sim): Populate turbostar.json and register testbenches via turbostar-verilog config --target ice40 --device hx8k --top main, lint/synthesize with compile, and run simulations with sim.
  • VCD Waveform Inspection (vcd-*): Inspect and debug simulation dumps from the command line with vcd-info, vcd-wave, vcd-search, vcd-compare, vcd-trace, vcd-labels, and vcd-qualifier—all rendered with UTF-8 box-drawing tables.

12 Specialized Tools Across the RTL Lifecycle

Activate the verilog tool family in Turbostar or expose it to any external agent CLI via turbomcp.

🛠️

Lint, Synthesis & Config

Fast static verification and persistent FPGA target configuration without manual Makefiles.

  • verilog_compile: Dual Verilator lint (lint_only=true in ~0.13s) + Yosys synthesis with submodule scoping.
  • verilog_project_settings: Configure target FPGA family (ice40, ecp5, gowin, xilinx), part, package, top module, and target clock MHz.
⚡

Tiered RTL Simulation

Automated testbench discovery, tiered execution, and regression waveform snapshots.

  • verilog_simulate: Run testbenches with hierarchical=true bottom-up verification and auto-diffing against .lastpass.vcd.
  • verilog_configure_testbench: Associate testbenches with modules in turbostar.json, assign levels (quick, comprehensive, extreme), and set defaults.
📈

Waveform Inspection

Token-efficient, clock-aligned VCD tables and temporal condition search.

  • vcd_file_info: Inspect hierarchy scopes, timescale, clock candidate ticks, and detect zero-toggle (**) inactive nets.
  • vcd_wave: Clock-aligned Markdown tables with posedge sampling, enum state names, and idle-cycle collapsing.
  • vcd_search: Find timestamps matching multi-signal boolean expressions or edge transitions.
🏷️

Semantic Trace & Diffing

Bridge raw signal bits back to high-level SystemVerilog types and source lines.

  • vcd_signal_labels: Auto-discover typedef enum state names and register project-wide value maps (vcd_labels.json).
  • vcd_signal_qualifier: Mask bus values with - during inactive valid/enable cycles.
  • vcd_compare: Cycle-by-cycle diff between two VCD traces with clock-edge alignment and divergence reports.
  • vcd_signal_to_code: Trace VCD nets to RTL declarations, drivers, and loads.
⏱️

Logic Depth & Area

Instant combinational LUT cone analysis and module resource tracking.

  • verilog_logic_depth: Per-module critical path hop traces, sink grouping, carry chain analysis, and LUT/FF area summaries.
  • verilog_update_timing: Batch updater writing aligned // [timing: ...] port annotations directly in .sv module interfaces.
📐

Physical Place & Route

Post-routing timing closure with physical chip coordinates and routing delay breakdowns.

  • verilog_pnr_timing: Full Yosys + nextpnr physical timing analysis reporting Fmax, slack, logic vs. wire delay, fanout, and (dx, dy) tile distance.
  • turbostar-verilog: Unified standalone CLI for project config (config), logic depth, physical PnR (--pnr), batch in-place port annotations (-u), compile/sim, and vcd-* waveform tools with UTF-8 framed terminal tables.

Open-Source FPGA Toolchain Setup

Turbostar integrates directly with standard open-source SystemVerilog and FPGA synthesis packages.

1. Install EDA Dependencies & Project Template

Install the open-source verification and synthesis tools from your distribution package manager or OSS CAD Suite. Turbostar also ships with a ready-to-use systemverilog project template containing a pre-configured turbostar.json and an agent workflow guide (AGENT.md).

  • Lint & Simulation: verilator and iverilog (Icarus Verilog + vvp).
  • Synthesis & Logic Depth: yosys (supports generic gate synthesis plus ice40, ecp5, gowin, and xilinx targets).
  • Physical Place & Route: nextpnr-ice40, nextpnr-ecp5, or nextpnr-gowin alongside fpga-icestorm / prjtrellis.
# 1. Install open-source RTL & FPGA tools (Debian/Ubuntu)
sudo apt install yosys verilator iverilog \
  nextpnr-ice40 fpga-icestorm

# 2. Activate in an agent session or via MCP
# Call activate_tool_family(name="verilog")
# or launch turbomcp with --all-tool-families
turbomcp --project-dir /path/to/rtl-project

# 3. Or run the standalone human CLI
turbostar-verilog config --target ice40 --device hx8k --top main
turbostar-verilog -m alu_mod
turbostar-verilog --pnr --seeds 4
turbostar-verilog -u
