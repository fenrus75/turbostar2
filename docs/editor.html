A Highly Productive TUI

Classic Aesthetics, Modern Power

Turbostar provides a distraction-free, highly responsive workspace in the terminal. It pairs nostalgia with the robust utility developers demand for complex C++ and Python projects.

Multi-Window Tiled Workspace

Turbostar splits screen real estate dynamically, supporting multi-document layouts. Window boundaries are double-bordered, drop-shadowed, and react natively to mouse events for resizing and dragging.

  • Mouse Interception: Click and drag coordinates-free layouts natively. Hold Shift to override and trigger your terminal emulator's native selection.
  • Linked Windows: Opening complementary files binds window pairs (e.g. Code Review edits & compiler outputs) so they move and cycle focus synchronously.
turbostar src/main.cpp

Developer Native: Compile, Run & Debug

Designed specifically for low-level systems developers. Compile, run, and debug applications directly within the editor interface, keeping you fully in your workspace without context switching.

  • In-Editor Compilation: Build your projects with standard toolchains (Meson, Make, GCC/Clang) instantly, with real-time feedback and direct error navigation.
  • Interactive GDB Debugging: Perform single-stepping, set breakpoints, and inspect variables using an integrated gdbserver environment inside the TUI editor window.
turbostar --debug

Crash Catcher & Core View Manager

Never get stuck debugging segmentation faults or lose your terminal state. Turbostar integrates libturbocatch.so to intercept failures, alongside a built-in Core View Manager to inspect crash dumps directly within the editor.

  • Real-time Signal Interception: Catches unexpected crashes (SIGSEGV, SIGABRT, failed assertions) during manual runs or automated tests.
  • Aggregated Logs & Core Inspection: Displays recent application coredumps, complete with dates, target binaries, active thread identifiers, and register states.
  • Source Code Linking: Parses the backtrace dynamically, automatically linking crash locations back to the exact filename and line number in the editor for immediate debugging.
  • Graceful Terminal Restoration: Instantly resets TUI terminal configurations back to standard modes on fatal signals, keeping your shell functional.
turbostar --crash-manager

Keyboard Quick Reference

Turbostar utilizes WordStar/Joe-style keybinding structures for block selections, search controls, and text deletions. Rather than relying on modern key combinations or menu bar navigation, developers can execute standard commands using prefix keys.

The explicit design goal of Turbostar is to be Joe "finger compatible", ensuring that muscle memory from classic Joe and WordStar editors maps natively to editing actions, while maintaining full support for traditional Turbo Pascal keys (like F2 to save, F3 to load, and F10 to open the main menu).

Key sequences are structured logically: Block Commands begin with Ctrl+K (e.g., ^K B to mark start, ^K K to mark end, ^K C to copy, ^K Y to delete), while Navigation & Deletions map directly to standard terminal signals (e.g., Ctrl+A for start of line, Ctrl+E for end of line, Ctrl+Y to delete a line).
